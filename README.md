# NAVIS - Nautical Analysis & Vessel Intelligence System

NAVIS is an intelligent maritime vessel detection and tracking system that combines real-time computer vision with natural language interaction. The system uses a two-agent architecture to provide comprehensive vessel analysis, motion tracking, and interactive querying capabilities.

## Overview

NAVIS is designed for analyzing vessel behavior in maritime environments, particularly from aerial drone footage. The system provides:

- **Real-time Vessel Detection**: YOLOv8-based detection with fine-tuned maritime vessel models
- **Intelligent Tracking**: Multi-object tracking with motion analysis (velocity, speed, acceleration, direction)
- **Natural Language Interface**: Chat-based querying of vessel data, metrics, and events
- **Interactive Visualizations**: Real-time plots and motion calculations display
- **Event Detection**: Automatic detection of sharp turns, jerky motion, and erratic driving patterns
- **Distance Calculations**: Measure distances between vessels
- **Comprehensive Analytics**: Motion summaries, comparisons, and detailed per-track analysis
